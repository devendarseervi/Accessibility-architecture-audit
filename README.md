# Internship Task 02 — Accessibility Audit & Project Foundation

## Overview

This repository contains an accessibility audit of the National Portal of India Services website and the foundation for a full-stack web application.

**Website audited:** https://services.india.gov.in/

## Objectives

- Run a Lighthouse accessibility audit.
- Perform keyboard-only accessibility checks.
- Document accessibility findings and recommended fixes.
- Establish a maintainable full-stack project structure.
- Document architecture and local setup instructions.

## Repository Structure

- `client/` — Frontend application
- `server/` — Backend application
- `docs/` — Audit report and architecture documentation
- `tests/` — Automated tests
